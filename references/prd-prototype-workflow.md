# PRD and prototype workflow

Use this PRD structure:
- Executive summary
- Problem and evidence
- User and use cases
- Goals and non-goals
- Proposed experience
- Requirements
- Decision logic and edge cases
- Measurement and experiment plan
- Risks and controls
- Dependencies and rollout
- Open questions

Prototype the riskiest workflow or interaction. Include realistic but clearly labeled sample data when live data is unavailable. Keep the prototype traceable to requirement IDs.
